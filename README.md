# ⚡ Real-Time Chat App (WebSockets)

A full-stack real-time chat application built using **raw WebSockets** (no Socket.io).

## 🎥 Demo Video

[![Watch Demo](https://res.cloudinary.com/diery17cm/video/upload/so_1/IMG_0691_knrgne.jpg)](https://res.cloudinary.com/diery17cm/video/upload/v1767116107/IMG_0691_knrgne.mov)


## ✨ Features

- Real-time messaging (WebSockets)
- Online / Offline users
- Authentication
- Optimized WebSocket lifecycle
- Clean architecture

## 🛠 Tech Stack

- **Next.js** for pure frontend.
- **Node.js** for backend
- Express
- WebSockets `(ws)`
- Zustand
- TypeScript

## 📦 Deployment

- Frontend: Vercel
- Backend: Render
